Conectar ao GitHub

Para o painel salvar suas alterações direto no site. O token fica só neste navegador.

Como criar o token: github.com/settings/personal-access-tokens/new → escolha só este repositório → em Permissions, marque Contents: Read and write → Generate token → cole acima.

Como usar

1. Conecte ao GitHub na aba Conexão GitHub (só uma vez).
2. Em Produtos, toque em + Produto, preencha nome, descrição e preço, e adicione fotos e vídeos (link ou arquivo do computador).
3. Toque em Salvar no GitHub. O site atualiza sozinho em cerca de 1 minuto.

Fotos e vídeos: a primeira da lista aparece primeiro; o cliente passa para o lado para ver as outras. Vídeo toca sozinho, sem som. Prefira vídeo curto (até 20 MB) em formato MP4.
Modo da foto: Automático deixa a foto em tela cheia. Use Produto (fundo branco) para garrafa ou lata com fundo branco; ele vira um fundo amarelo e verde. Inteira mostra a foto sem cortar.
Lista de itens: serve para vários itens numa tela só (ex.: sabores de pastel).
Sem conexão: dá para editar e usar Baixar cardapio.js, mas só o GitHub guarda de verdade.
